# MedTrack Lite

**Smart Pharmacy Inventory and Expiry Management System**

## Project Overview

MedTrack Lite is a web-based pharmacy management system enhanced with Artificial Intelligence (AI) and Machine Learning (ML). The system is designed to improve medicine safety, reduce human error, and support data-driven decision-making in pharmacy operations.

## Features

* Drug Inventory Management (Add, Edit, Delete, Search)
* Automated Expiry Monitoring (Prevents sale of expired drugs)
* Low Stock Alerts (<10 units)
* Demand Forecasting (7-day and 14-day predictions using ML)
* Fraud Detection (Anomaly Detection for unusual transactions)
* Expiry Risk Analysis
* Staff Performance Analytics
* Smart Analytics Dashboard
* Role-Based Access Control (Admin & Staff)
* Reporting System

##  AI & Machine Learning Features

* Demand forecasting using time-series and regression models
* Anomaly detection for suspicious transactions
* Expiry risk scoring based on stock and expiry dates
* Staff performance analytics

## Technologies Used

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** PHP
* **Database:** MySQL
* **Machine Learning:** Python
* **Tools:** VS Code, XAMPP, phpMyAdmin

## System Requirements

* PHP 7.4+
* MySQL 5.7+
* Apache Server (XAMPP recommended)
* Web Browser (Chrome, Edge, Firefox)

## How to Run the Project

1. Clone or download the repository
2. Move the project folder to:

   ```
   htdocs/ (for XAMPP)
   ```
3. Start Apache and MySQL in XAMPP
4. Import the database:

   * Open phpMyAdmin
   * Create a database
   * Import the `.sql` file from `/database`
5. Open browser and run:

   ```
   http://localhost/medtrack-lite
   ```

##  User Roles

* **Admin:** Full system control (manage users, drugs, reports, analytics)
* **Staff:** Process sales, view inventory, track performance
